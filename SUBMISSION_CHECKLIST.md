# Submission checklist

## Repository / assignment 1
- [ ] Public repository opens without authentication.
- [ ] Clean-clone setup works using README instructions.
- [ ] `pytest -q` passes; attach the test output.
- [ ] `storyboard.json` validates; schema and semantic checks are documented.
- [ ] `runs.jsonl` contains real stage calls, hashes, latency, status, and cost estimates where available.
- [ ] `ARCHITECTURE.md`, `DESIGN.md`, `ETHICS.md`, `COSTS.md`, `EXPERIMENTS.md`, and `FAILURES.md` contain measured/project-specific evidence.
- [ ] Consent and exact model/checkpoint licenses reviewed; no secrets or private consent evidence committed.
- [ ] Final report uploaded as PDF/Word or accessible link.
- [ ] Prepare to explain architecture, one experiment, one failure, audience feedback, and design trade-offs.

## Film / assignment 2
- [ ] 60–90 second vertical 9:16 MP4 uploaded and publicly accessible (main submission link).
- [ ] Horizontal 16:9 MP4 uploaded and publicly accessible.
- [ ] English subtitles are legible and synchronized in both formats.
- [ ] Amharic narration pronunciation reviewed by a fluent/native speaker.
- [ ] Original music candidate selected and rationale stored in storyboard.
- [ ] Music is ducked under narration and final loudness checked.
- [ ] AI disclosure end card is visible.
- [ ] Consent and release gates pass; final QC report saved.
- [ ] Walkthrough video (maximum five minutes) uploaded.
- [ ] Public post link supplied, or screenshot attached if not posting publicly.
